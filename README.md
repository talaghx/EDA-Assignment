# Airbnb Listings EDA

## Dataset Source
The dataset was obtained from Kaggle:
https://www.kaggle.com/datasets/darkmatternet/airbnb-listings-nyc-london-paris-tokyo-and-more

## Description
This dataset contains information about Airbnb listings including price, location, and availability.

## Purpose
The purpose of this project is to perform Exploratory Data Analysis (EDA) to explore patterns and trends in the dataset.
